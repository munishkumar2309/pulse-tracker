# Changelog

Newest first. One line per change: date, area, what changed, which files and docs.

## 2026-11-18
- **Food photo recognition.** Add food → 📷 Photo. On the phone by default: `dima806/indian_food_image_detection` (ViT, 80 Indian dishes, Apache-2.0) via Transformers.js 4 + ONNX Runtime Web; the photo never leaves the phone. Optional cloud recognition (You → Food photos) with Claude vision and the user's own Anthropic API key, for thalis and portion guesses. Calories come from Pulse's data, not the model. 26 dish estimates added to cover the model's labels. API key kept out of backups (`secret:` meta rows). Tested in the browser with a stand-in ONNX model of the same shape (Hugging Face was blocked in the build sandbox); the real model and the cloud call are not yet tested. 130 tests. (components/FoodPhoto.tsx, health/foodVision.ts + test, health/foodRecognizers.ts, data/foodLabels.ts, data/dishes.ts, screens/Food.tsx, Settings.tsx, scripts/export-food-model.py, vite.config.ts, package.json; docs/HEALTH.md, ARCHITECTURE.md, UI.md, ANDROID.md; privacy policy)
- **Month-wise comparison and auto-categorising.** "vs last month" is now like-for-like for the month in progress (days 1..today against the same days of last month); before, a part month was compared with a full one. New "Compared with <month>" card (per-category change, biggest rise, where you spend the most) and a month-by-month list under the Month chart. Investments are now kept out of spend and shown as "Invested" (the intent of the previous change; the code still counted them). Rows stuck in Other are re-categorised automatically when Money opens; hand-picked categories (new `userSet` field, not indexed, so no schema version bump) are never touched. About 60 more merchant keywords (medical/chemist, dairy/milk, toll, insurance, Lenskart and others). 123 tests. (money/insights.ts, categorize.ts, ingest.ts, money.test.ts, data/categories.ts, db/schema.ts, screens/Money.tsx, Settings.tsx; docs/MONEY.md, UI.md)
- **UI v2: Fitbit-style redesign, motion, app lock, GPS, interactive money charts.**
  - Theme: shadcn tokens (Nova preset) with the old names aliased; Geist font.
  - Motion: rings, count-up, tile stagger, tab pill, page fades (reduced-motion respected), plus haptics.
  - Today: hero steps ring + readiness card + tile grid.
  - New Activity tab: 7-day steps chart; GPS walk/run tracking with a Leaflet/OSM live map, pace, distance and a kcal estimate (`health/geo.ts` + 10 tests); walk history (schema v2 `walks`).
  - Money: interactive donut (tap to filter), Day/Week/Month spend bars, Overview/Transactions tabs.
  - App lock: fingerprint/face with screen-lock fallback and a relock delay.
  - Theme switching moved to `lib/theme.ts` (fixes forced dark); shadcn MCP added (`.mcp.json`); phone-sensor sleep labelled as an estimate; backups include walks.
  - Files: src/index.css, App.tsx, main.tsx, components/*, screens/*, native/lock|gps|haptics.ts, lib/theme.ts, health/geo.ts, db/schema.ts v2, db/hooks.ts; docs/UI.md, ANDROID.md, ARCHITECTURE.md.
- **Phone step + sleep tracking and home-screen widgets.** Steps from the phone's own sensors via Google's on-device Recording API, and sleep via the Sleep API (motion + light), both running in Play services even when Pulse is closed. New `source: 'phone'`. Merge rules: manual wins; steps keep the higher of phone/Health Connect; a Health Connect night replaces an overlapping phone night. Two widgets: Pulse · Today (steps, sleep, water, spent) and Pulse · Steps (goal bar). New ACTIVITY_RECOGNITION + RECEIVE_BOOT_COMPLETED permissions. Native code not yet compiled (no local SDK): first CI build is the check.
